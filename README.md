# 3D Heat Diffusion

1. Распакуй архив и открой Heat3D.sln в Visual Studio.
2. Выбери Release и x64. Нажми зелёную кнопку запуска или Ctrl+F5.
3. Дождись таблицы и строки PASS: all comparisons matched.

Для сборки нужны Visual Studio 2026 с C++ и Microsoft MPI SDK. Для запуска нужен Microsoft MPI Runtime. На компьютере, где проект проверялся, всё уже установлено. Visual Studio сама собирает программу и запускает три MPI-процесса.

В одном запуске программа сравнивает Serial, OpenMP (2, 4 и 8 потоков), MPI blocking и MPI overlap (по 1 и 2 потока на процесс). Время — медиана трёх повторов. Speedup = время Serial / время режима. Eff. % = 100 × Speedup / (число процессов × число потоков на процесс). Max error — максимальная разница температур с последовательной версией. В конце отдельно выводится ошибка на задаче с известным решением.

Код находится в heat.cpp. OpenMP делит строки сетки между потоками, MPI делит сетку на слои вдоль Z. При неблокирующем обмене внутренние плоскости считаются, пока идут передачи, а края обновляются после получения данных.

diffusion.png показывает центральный срез после 1, 30 и 120 шагов. Графики презентации показывают предыдущую серию замеров, в том числе слабое масштабирование. Живое сравнение использует фиксированную сетку 224 × 224 × 226 и три MPI-процесса; поэтому значения в консоли могут отличаться от слайдов.

## Модель и начальное состояние

На равномерной сетке решается уравнение теплопроводности ∂T/∂t = α∇²T явной схемой. Для каждой внутренней ячейки T_new = (1−6r)T_old + r·sum(шесть соседей), где r = αΔt/h² = 0,12 ≤ 1/6. Два буфера отделяют старое поле от нового. На шести внешних гранях всегда T = 0. Внутри T = 100·exp(−90·d²), где d — расстояние до точки (0,48; 0,51; 0,43) в нормированных координатах сетки.

Для MPI первые ранги получают по дополнительной плоскости, если число внутренних плоскостей по Z не делится на число процессов. Каждый процесс пишет только в свой блок; две ghost-плоскости служат для обмена с соседями. Потоки OpenMP делят строки статически, сохраняя проход по X непрерывным.

## Сборка из командной строки

В Developer Command Prompt for Visual Studio из папки репозитория:

```cmd
msbuild Heat3D.sln /p:Configuration=Release /p:Platform=x64
mpiexec -n 3 bin\Release\heat.exe
```

Если mpiexec не в PATH, используй полный путь к Microsoft MPI\Bin\mpiexec.exe. Проект использует MSVC v145, C++17, /O2 и /openmp. Нужны MS-MPI Runtime и SDK.

## Условия экспериментов и результаты

- Один компьютер: Intel Core i5-11400H, 12 логических процессоров, Windows 11 25H2 (build 26200), MSVC x64, Microsoft MPI. Между компьютерами обмен не измерялся.
- Текущий запуск: 224 × 224 × 226, 42 шага. Три повтора после прогрева; в таблице медиана. Для MPI берётся время самого медленного ранга за каждый повтор.
- [Вывод текущего запуска](results/live-console.txt): времена, ускорение, эффективность и максимальная абсолютная ошибка каждого режима. Допуск 1e-10; в конце отдельная проверка по дискретной синусоидальной моде.
- [Исходные замеры для слайдов](results/original-measurements.json): размеры, шаги, процессы, потоки, медианы и все три повтора каждой конфигурации. Strong scaling сравнивается с Serial на той же сетке. Weak scaling сравнивается с одним MPI-рангом при одинаковых 24 внутренних плоскостях на ранг; отдельный Serial для каждого слабого размера не измерялся.
- [Исходные проверки](results/original-verification.json): параметры и ошибки десяти тестов. Это предыдущая серия, а не повтор текущего запуска.
