# 3D Heat Diffusion

A C++ simulation that compares serial, OpenMP, and MPI + OpenMP implementations.

**Run:** Install Visual Studio with C++ support and Microsoft MPI (Runtime and SDK). Open `Heat3D.sln`, select **Release | x64**, and press **Ctrl+F5**.

The console reports runtime, speedup, efficiency, and error against the serial result.
